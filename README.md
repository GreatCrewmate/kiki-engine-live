# Kiki Engine (Live) - An engine for Friday Night Funkin'

Kiki Engine is an engine that uses [Godot Engine](https://godotengine.org/). This engine might be awesome if a lot of work is done.

This repository will have:
- Changelogs
- Current version (as a file)
- Public builds (check "Releases" tab if there are any available now)

> [!NOTE]
> If you found this repository page, please, don't spread it globally.

---

> [!WARNING]
> This repository is used for some tests for now. So during some tests, it might have teasers or ***leak stuff!***

> [!TIP]
